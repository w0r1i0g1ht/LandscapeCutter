# 里程碑 3 执行进度

## 已实现

- 六类标注工具：矩形、椭圆、箭头、画笔、文字和马赛克；对象支持选择、移动、调整、删除、撤销和重做。
- 预览、剪贴板、PNG 与 JPEG 共用标注渲染路径。剪贴板与 PNG 保持 RGB32 像素，JPEG 质量为 90。
- 跨屏标注共享一个工具栏宿主；文字编辑器也只在该宿主创建。
- 导出在 GUI 线程冻结选区或标注文档快照，工作线程合成/编码；取消与原子提交共享最终同步边界，显示失效和过期请求不会提交旧结果。
- 会话析构会在工作线程结束后排空 deferred-delete，避免局部 QApplication 退出时遗留顶层 overlay。

## 自动验证

- MSVC Debug Ninja 构建成功。
- 默认自动测试 212/212 通过；真实桌面测试 4/4 通过。
- 跨屏草稿工具栏回归连续运行 5 次通过；直接/标注导出的成功、失败、取消、过期完成和析构等待均有会话测试覆盖。
- PNG 精确 round-trip 与 JPEG 解码尺寸/平均 RGB 误差阈值（不超过 12）由 SnapshotImage 测试覆盖。
- 1024 × 1024 马赛克导出并触发显示失效的隔离测试耗时约 0.30 秒（含测试进程启动），用于回归约束而非产品性能基准。

## 当前硬件覆盖与人工验收

当前桌面测试检测到 1 台 1920 × 1080、96 × 96 DPI、SDR 显示器；捕获一帧约 109 毫秒。离屏测试覆盖合成跨屏坐标，但不替代真实多显示器、负坐标、混合 DPI 或 HDR 硬件。人工验收仍需验证六种工具、文字编辑、属性、撤销/重做、剪贴板、PNG 和 JPEG 输出。
