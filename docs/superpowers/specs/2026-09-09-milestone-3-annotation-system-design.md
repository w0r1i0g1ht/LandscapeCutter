# 里程碑 3：标注系统详细设计

状态：用户于 2026-09-09 确认设计方向；书面规格复核问题已修正。

## 依据与目标

里程碑 2 已在提交 `8d0871e` 完成全显示器冻结、物理像素选区、剪贴板和 PNG/JPEG 保存。
本里程碑依据上位设计的 `annotation` 模块与第 7、11、13 节，实现矩形、椭圆、箭头、自由画笔、
文字和马赛克六类标注，以及属性编辑、撤销、重做和统一合成。

退出条件是六类工具均可完成创建和适用编辑，每次已提交操作可撤销和重做，屏幕预览、剪贴板、
PNG 与 JPEG 使用同一标注文档和渲染规则。捕获与显示器模块不感知标注对象。

## 范围

本里程碑包含：

- 六类标注对象的值模型、当前草稿、当前选中对象和工具状态；
- 对象创建、选择、移动、适用的几何调整、属性修改和删除；
- 最多 100 条对象级命令历史，支持撤销与重做；
- 选区确定后的标注状态、单一工具栏宿主和跨屏预览；
- 预览、复制与保存共用的确定性渲染器；
- 取消、显示变化和异步导出的过期结果抑制；
- 自动测试与当前硬件环境的人工验收。

本里程碑不包含界面视觉重做、用户自定义主题、标注对象持久化、工程文件、图层面板、OCR、序号、
贴图或实时捕获。手柄鼠标形状、捕获鼠标开关和整体外观继续按现有体验优化计划延后。

## 方案选择

采用独立 `src/annotation/` 值模型、命令历史、输入状态机和共享渲染器。`snip` 只负责把冻结选区
转换为标注底图，并把窗口输入与导出请求交给该模块。

未采用直接把每次笔画烧录进 `QImage` 的方案，因为它无法可靠修改已有属性，也会迫使撤销历史保存
整张图像。未采用 `QGraphicsScene` 作为文档真相，因为多窗口、混合 DPI 与工作线程最终合成需要额外
同步另一套场景状态，容易造成预览和输出不一致。

## 模块边界

新增以下单元：

- `AnnotationTypes`：工具、样式、对象 ID、六类对象和不可变渲染快照；
- `AnnotationDocument`：不可变 DPR=1 底图、已提交对象、当前选择、当前草稿和当前工具属性；
- `AnnotationHistory`：对象级命令、撤销/重做游标和 100 条上限；
- `AnnotationInteraction`：不依赖 QWidget 的指针和编辑状态机；
- `AnnotationRenderer`：唯一的标注绘制、马赛克处理和最终 `QImage` 合成实现。

修改 `SnipSession` 以管理状态、异步准备底图和导出不可变快照；修改 `SnipOverlay` 以路由输入、显示
工具栏和调用共享渲染器。`capture`、WGC、D3D11 回读和 `SnapshotBatch` 的职责不变。

## 文档和对象模型

标注文档坐标以已锁定选区左上角为 `(0,0)`，单位始终是输出物理像素。原生鼠标输入先从桌面
物理坐标减去选区原点，再进入交互状态机。预览阶段才将文档坐标映射到各遮罩的 Qt 局部坐标；
最终输出直接绘制到 DPR=1 的底图，不进行 DPI 重采样。

每个对象包含单调递增的 `uint64_t` ID 和以下一种负载：

- 矩形、椭圆：规范化 `QRectF`、描边颜色与物理像素线宽；
- 箭头：起点、终点、颜色与线宽；
- 自由画笔：按输入顺序保存的点列、颜色与线宽；
- 文字：锚点、正文、颜色和物理像素字号；
- 马赛克：规范化区域和整数块大小。

首版默认样式为红色、3 物理像素线宽、24 物理像素字号和 12 物理像素马赛克块。工具栏允许修改
当前工具的适用属性；选中已有对象时，属性修改作用于该对象并进入命令历史。外观样式以后可调整，
这些数值只定义功能基线。

对象按创建顺序保持稳定。马赛克在独立效果层按创建顺序处理不可变底图，所有矢量和文字对象随后按
创建顺序绘制，使箭头、文字和轮廓始终清晰位于马赛克之上。实际视觉层级为“马赛克层在下，矢量与
文字层在上”，每层内后创建的对象在更上方；选择命中严格按该视觉层级的逆序检查。选中框、控制点、
悬停状态和文字编辑器只属于交互 UI，不进入最终输出。

## 状态与用户流程

会话状态为：

```text
PreparingCapture → Selecting → PreparingAnnotation → Annotating
                      │                    │
                      ├─直接复制/保存─────→ ExportingFromSelection
                      └─准备失败──────────→ Selecting
                                           └─标注复制/保存→ ExportingAnnotated

ChoosingSavePath ──取消──→ 调用前的 Selecting 或 Annotating
ExportingFromSelection ──失败──→ Selecting
ExportingAnnotated ──失败──→ Annotating
任一导出状态 ──成功──→ Idle
任意状态 ──取消/显示变化/退出──→ Idle
```

里程碑 2 的直接复制和保存路径继续保留。用户得到有效选区后，可立即 Enter、Ctrl+C、双击、Ctrl+S
完成无标注输出。用户点击任一标注工具时，当前选区被锁定，工作线程合成一次 DPR=1 底图；准备完成
后进入标注状态。标注存在期间不允许移动或缩放截图选区，从源头避免对象坐标失效。

标注工具栏复用里程碑 2 的唯一宿主规则，不在每个显示器创建重复控制。工具包括选择、矩形、椭圆、
箭头、画笔、文字和马赛克，以及颜色、线宽或适用参数、撤销、重做、删除、复制、保存和取消。

快捷键规则：

- Ctrl+Z 撤销；Ctrl+Y 和 Ctrl+Shift+Z 重做；Delete 删除当前对象；
- 无活动文字编辑时，Enter、Ctrl+C 复制最终结果，Ctrl+S 保存；
- 文字编辑使用 Ctrl+Enter 提交，Esc 取消本次文字草稿；普通 Enter 可输入换行；
- 文字编辑器持有焦点时优先消费 Delete、Ctrl+C、Ctrl+Z、Ctrl+Y 和 Ctrl+Shift+Z，分别执行正文
  删除、复制和编辑器本地撤销/重做；Ctrl+S 被消费但不保存，必须先提交或取消正文；
- Esc 优先取消当前草稿或几何编辑；没有活动草稿时取消整个截图会话；
- 标注状态中的双击用于重新编辑文字，不触发复制；Selecting 状态保留双击复制。

## 创建与编辑语义

矩形、椭圆和马赛克由按下点与当前点生成规范化区域；箭头保存有方向的起终点。箭头头部两边与
反向轴线夹角均为 28°，长度为 `min(max(8, 4 × 线宽), 0.4 × 箭杆长度)`；零长度箭头不提交。
画笔保存连续点列，首点必收录，后续点与最近收录点的欧氏距离达到 1.5 物理像素才收录，释放点不同于
最近点时始终追加；绘制使用折线、圆头和圆角连接。零面积形状、空白文字和不足两个不同点的画笔不提交。

选择工具按实际视觉层级从上到下命中：先逆序检查矢量和文字，再逆序检查马赛克。矩形和椭圆的整个
边界框内部均可选择；箭头和画笔的线段命中距离为 `max(6, 线宽 / 2 + 3)` 物理像素；文字使用由字体
度量得到的多行逻辑矩形并向外扩展 3 像素；马赛克使用整个区域。重叠时第一个命中的对象获选。
所有对象均可移动；矩形、椭圆和马赛克使用边角控制点调整区域，
箭头可调整两个端点，文字可移动并通过双击重新编辑，自由画笔首版支持整体移动但不做逐点编辑。
所有几何结果裁剪到文档范围内。

创建、移动、调整、删除、文字提交和一次属性修改各形成一条命令。鼠标移动过程只更新草稿或临时
编辑副本，释放时才提交一个 before/after 差异。撤销后执行新命令立即丢弃 redo 分支。超过 100 条时
丢弃最早命令；历史只保存对象值，不复制底图。

## 统一渲染

`AnnotationRenderer` 接收不可变 `AnnotationSnapshot`，其内容为共享底图和对象值副本。它提供：

- 将同一对象绘制规则应用到任意 `QPainter`、目标变换和裁剪范围，供每屏预览调用；
- 将底图复制为 DPR=1 输出图，应用马赛克效果，再绘制矢量和文字，供复制与保存调用。

矩形、椭圆、箭头和画笔启用抗锯齿，描边使用圆头与圆角连接。文字字体按 `Segoe UI`、
`Microsoft YaHei UI`、`Arial` 的顺序选择首个已安装字体，否则使用 Qt GeneralFont；使用正常字重、
非斜体且不自动换行。文字锚点是首行逻辑布局框左上角，首行基线为 `anchor.y + ascent`，每个换行符
按 `lineSpacing` 下移，制表符在提交前转换为四个空格。

马赛克块网格固定对齐文档 `(0,0)`，跨显示器预览不能各自重新起算。每个块从不可变 RGB32 底图中
取得覆盖像素的 R、G、B 算术平均值，使用 `(sum + count / 2) / count` 取最近整数并以不透明色填充；
边缘不足整块时只平均实际覆盖像素。

固定图像测试要求输出尺寸完全相同，马赛克内部像素完全相同；非文字抗锯齿像素逐通道误差不超过 2。
文字测试要求逻辑边界误差不超过 1 像素，边界内至少 95% 像素的逐通道误差不超过 16。

预览调用共享对象绘制函数，不另外实现一套图元算法。交互草稿也通过同一函数渲染，但不会出现在
不可变导出快照中，直到提交为正式对象。预览一致性测试把交互 UI 排除后，将已知变换下的预览层映射
回文档物理像素：非文字对象覆盖边界误差不超过 1 像素，文字使用上述 95%/16 阈值；它同时与最终
合成图减去同一底图所得的标注层比较，而不以“调用了同一函数”作为通过条件。

## 线程、取消与错误

GUI 线程拥有文档编辑、窗口、工具栏、文字编辑器和剪贴板。工作线程负责选区底图合成、最终图像
合成、PNG/JPEG 编码和原子保存。`QImage` 使用只读隐式共享；传给工作线程的对象集合为值快照。

准备底图和导出继续携带 SnipSession 请求 ID 与取消标记。直接导出失败恢复 Selecting，标注导出失败
恢复 Annotating，保存对话框取消恢复调用前状态；成功导出进入 Idle。取消、显示变化、新会话或应用退出后到达的
结果不得打开窗口、写剪贴板、提交文件或改变文档。析构在释放捕获和 D3D 资源前等待工作线程结束。

无法准备底图时保留选区并返回 Selecting，用户可重试或直接取消。无法渲染或保存时保留文档、选区
和历史，通过非阻塞托盘消息报告。文字正文、截图像素和剪贴板内容不得写入日志或测试输出。

## 测试与验收

单元测试覆盖：

- 六类对象值语义、文档边界和命中顺序；
- 每类创建与编辑的一次手势一条命令；
- 撤销、重做、redo 失效、删除、属性变更和 100 条历史上限；
- 坐标映射、几何裁剪、箭头头部和画笔点合并；
- 六类工具的固定 DPR=1 渲染、马赛克原点对齐和文字容差；
- 预览层映射回物理像素后满足已定义的覆盖范围和像素误差阈值。

会话与集成测试覆盖：

- 选区锁定、异步准备、取消和过期完成；
- Selecting 与 Annotating 的输入互斥；
- 文字编辑期间的 Enter/Esc 和普通状态快捷键；
- 直接导出失败返回 Selecting，标注导出失败返回 Annotating，保存对话框取消恢复调用前状态；
- 成功复制/保存后进入 Idle 并完整清理；
- 无标注路径保持里程碑 2 行为；
- 显示变化、快速 F2、Alt+F4、跨屏唯一工具栏和退出无残留。

最后运行完整 MSVC Debug 构建、默认 CTest 和真实桌面预设。人工验收六类工具、对象编辑、属性、
撤销重做与输出：剪贴板和 PNG 必须与最终合成图逐像素相同；JPEG 固定质量 90，解码尺寸必须相同，
测试夹具的 RGB 平均绝对误差不得超过 12。真实多显示器、负坐标、混合 DPI 和 HDR 若当前环境不具备，必须
明确记录为未覆盖，不用合成测试代替硬件证据。

## 实施顺序

1. 对象、样式、文档和有界命令历史；
2. 矩形、椭圆、箭头和自由画笔的共享渲染；
3. 会话状态与可取消的异步底图准备；
4. 前四类工具的输入路由、选择编辑和唯一工具栏；
5. 文字输入、重编辑和确定性渲染；
6. 基于不可变底图的马赛克；
7. 统一复制/保存、完整回归、文档和人工验收。
